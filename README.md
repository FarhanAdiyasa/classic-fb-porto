# Classic Facebook Style Portfolio

A nostalgic, high-performance web portfolio inspired by the classic 2005-2008 Facebook UI. Built with modern web technologies, this project blends retro aesthetics with contemporary engineering principles.

![Portfolio Preview](https://github.com/FarhanAdiyasa/classic-fb-porto/blob/main/public/preview.png?raw=true)

## 🚀 Features

- **Classic FB Aesthetic**: Meticulously recreated legacy UI including the blue header bar, tabbed navigation, and sidebar layouts.
- **Dynamic Content**: Highly manageable data structure through a centralized `constants.ts` file.
- **Responsive Design**: Adapts the classic desktop layout into a functional mobile-friendly experience.
- **AI-Powered (Optional)**: Integration-ready for Large Language Models (LLMs) like Gemini for profile descriptions or interactive elements.
- **Performance**: Instant load times thanks to Vite and optimized asset management.

## 🛠 Tech Stack

- **Framework**: [React.js](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Netlify](https://www.netlify.com/)

## 📂 Project Structure

- `src/App.tsx`: Main application logic and routing state.
- `src/constants.ts`: The central "database" for experiences, projects, and education.
- `src/components/`: Reusable UI components for the classic layout.
- `public/`: Static assets and profile images.

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/FarhanAdiyasa/classic-fb-porto.git
   cd classic-fb-porto
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
